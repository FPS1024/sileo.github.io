FPS1024 Sileo Repo

Personal APT repository for jailbroken iOS and iPadOS devices.

Overview

This is a personal package source maintained by FPS1024. It currently serves a small set of packages built for the iphoneos-arm64 architecture.

Packages are built and published as GitHub Releases in their own source repositories. This site only provides the APT index and the package list. A GitHub Actions workflow rebuilds both from those releases, and package downloads are served directly by GitHub, so the published site stores no binary packages.

Add this repository to Sileo

Add the following address as a source in Sileo:

https://fps1024.github.io/sileo.github.io/
  1. Open Sileo and go to Sources.
  2. Tap + and paste the repository URL.
  3. Refresh the source, then install a package.
